# Release v1.0.0 - Production-Ready Launch

Welcome to the initial stable release of AgenticDome Security Shield v1.0.0.

This release introduces a native, infrastructure-level firewall middleware for OpenClaw environments,
adding multi-tenant perimeter controls, zero-trust policy routing, delegated-agent authorization, and
transcript-safe output redaction.

## Key Enhancements

### Prompt Injection Shielding

The `before_agent_run` hook screens inbound prompts before agent execution begins.

This helps block context jailbreaks, prompt extraction attempts, system override strings, and malicious
instruction injection before task processing starts.

Requires:

```bash
openclaw config set plugins.entries.agenticdome-security.hooks.allowConversationAccess true
```

### Manager-to-Specialist Authorization Tokenization

The before_tool_call hook intercepts direct tool execution and delegated agent handoffs.

AgenticDome mints and validates ephemeral _decision_token values to prevent unauthorized lateral authority
jumps between manager and specialist agents.

### Transcript-Safe Output Redaction

The tool_result_persist hook performs synchronous local redaction before OpenClaw persists tool-result
messages.

This protects transcripts from leaked API keys, access tokens, bearer credentials, emails, phone numbers,
SSNs, and other sensitive text patterns.

## Structural Framework Compliance

- Built with tsup for modern ESM and CommonJS distribution.
- Publishes runtime entry files through dist/index.mjs and dist/index.cjs.
- Declares OpenClaw plugin loading through openclaw.extensions.
- Includes dist in the npm package whitelist so installed packages contain the compiled runtime files.
- Keeps tool_result_persist fully synchronous to match OpenClaw runtime expectations.

Install and enable the plugin with the OpenClaw CLI:

```bash
openclaw plugins install npm:agenticdome-openclaw-security
openclaw plugins enable agenticdome-security
openclaw config set plugins.entries.agenticdome-security.hooks.allowConversationAccess true
openclaw gateway restart
```

Then configure your AgenticDome tenant credentials:

```bash
export AGENTICDOME_API_BASE="https://au.agenticdome.io"
export AGENTICDOME_API_KEY="<your_api_key>"
export AGENTICDOME_TENANT_ID="<your_tenant_id>"
```
